# 💰 Smart Bill Splitter

> **Split expenses, not friendships!**  
> A fast, elegant, and privacy-focused web application for managing group expenses, calculating balances, and settling debts with minimal transactions.

🔗 **Live Demo:** [https://knitinnn.github.io/smart-expense-splitter/](https://knitinnn.github.io/smart-expense-splitter/)

---

## ✨ Key Features

- **🚀 Direct Dashboard Access & Privacy-First**:
  - No registration or login required.
  - 100% client-side: all data is stored securely in your browser's `localStorage` — nothing is sent to cloud servers.

- **📋 Group & Event Management**:
  - Organize shared costs by events (e.g., *Goa Trip*, *Weekend Dinner*, *Flatmates*).
  - Add members easily and manage custom event details.
  - Duplicate events or delete specific events with a single click.

- **💸 Multi-Payer & Flexible Expense Splitting**:
  - One expense can be paid by multiple people (contributors).
  - Select exactly who participated in each expense for accurate, fair splits.
  - Categorize expenses (*Travel, Food, Hotel, Drinks, Shopping, Miscellaneous*).

- **🤝 Smart Debt Settlement Algorithm**:
  - Automatically calculates net balances (who owes what).
  - Generates optimized, minimal repayment transactions (*Who Pays Whom*).

- **📊 Visual Analytics & Insights**:
  - Interactive category spending breakdown pie charts.
  - Monthly spending trends and expense summaries.

- **📥 Multi-Format Exporting & Printable Reports**:
  - Export event summaries to **JSON** or **CSV**.
  - One-click **Print / PDF Export** with clean invoice-ready styling.

- **🌓 Dark Mode & Responsive Design**:
  - Clean beige modern aesthetic with smooth transitions.
  - Full Dark Mode support.
  - 100% mobile-friendly and responsive.

- **🧹 Complete Data Control**:
  - Single event deletion.
  - Global "Delete All" feature to clear all data with safety confirmation prompts.

---

## 🛠️ Built With

- **HTML5**: Semantic markup and accessibility-ready structure.
- **Vanilla CSS3**: Custom design tokens, CSS variables, glassmorphism, responsive grid & flexbox layouts, dark mode.
- **Vanilla JavaScript (ES6+)**: Pure client-side application logic, settlement algorithm, history API routing, and HTML5 Canvas for dynamic charts.
- **Web Storage API (`localStorage`)**: Persistent offline-first data management.

## 🚀 Getting Started Locally

No complex build setup or dependencies needed! You can run this project in any modern web browser.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/knitinnn/smart-expense-splitter.git
   cd smart-expense-splitter
   ```

2. **Open the project:**
   - Double-click `index.html` to open it directly in your browser, or
   - Use a local dev server (e.g. VS Code Live Server or `npx serve .`).
